Nuestra Historia

Nacidos para Pregonar las Buenas Nuevas

La Casa de Oración para Todas las Naciones (IMCOTNV) y su ministerio radial RadioVisión RTV nacieron por una convicción profunda en el corazón de siervos de Dios que entendieron el llamado apostólico y profético de nuestro tiempo: "Pídeme y te daré por herencia las naciones" (Salmos 2:8). Con el lema "Oración • Palabra • Misión", desde la provincia de Cotabambas, Challhuahuacho, Dios levantó este altar de adoración y proclamación de la verdad.

A través de cultos llenos de la presencia del Espíritu Santo, la apertura de anexos en comunidades nativas y altoandinas, y la emisión radial ininterrumpida las 24 horas del día, miles de familias han sido alcanzadas, consoladas y restauradas para la gloria de Jesucristo.

Solución: Permisos de Firebase

Missing or insufficient permissions

Google Firebase bloqueó la sincronización debido a sus Reglas de Seguridad (modo producción o prueba vencida). Para desbloquearlo en 30 segundos:

1 Abre tu consola: console.firebase.google.com
2 Entra a tu proyecto > Firestore Database > pestaña superior Reglas (Rules).
3 Reemplaza las reglas actuales por este código: 
rules_version = '2';

service cloud.firestore {
  match /databases/{database}/documents {
    match /radiovision_app/{document=**} { allow read: if true; allow write: if request.auth != null; }
    match /content/{document=**} { allow read: if true; allow write: if request.auth != null; }
    match /events/{document=**} { allow read: if true; allow write: if request.auth != null; }
    match /podcasts/{document=**} { allow read: if true; allow write: if request.auth != null; }
    match /prayers/{document=**} { allow read, create: if true; allow update, delete: if request.auth != null; }
    match /testimonials/{document=**} { allow read, create: if true; allow update, delete: if request.auth != null; }
    match /users/{userId} { allow read, write: if request.auth != null && request.auth.uid == userId; }
  }
}
4 Haz clic en el botón azul Publicar (Publish) en la consola de Firebase.
